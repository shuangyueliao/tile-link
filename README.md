# Tile Link · 连线消消乐

Free single-file HTML5 connect puzzle (onet / mahjong-link style). Tap pairs of
identical tiles whose connecting line turns at most twice and only crosses
empty cells. Clear the whole board before the 180-second timer runs out and
climb levels on bigger boards. One HTML file, zero assets.

**Play:** https://shuangyueliao.github.io/tile-link/

- Mouse / touch (tap two tiles), procedural canvas art & WebAudio sounds
- Glowing path highlight, 24 tile patterns, wrong match costs 5 points
- Shuffle ×2 + Hint ×1 per level, auto-shuffle when no moves remain
- Time bonus (remaining seconds × 2) on level clear, best score/level saved locally
